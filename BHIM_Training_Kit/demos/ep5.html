Why this matters

Every plug you add is a new door into your data

MCP (Model Context Protocol)A2A (Agent2Agent protocol)
ConnectsOne agent to tools and data (calendar, CRM, files)One agent to another agent, often at another company
Who decidesYour agent calls the tool and gets a result backThe other agent has its own model and rules; you only see its answer
DiscoveryServer lists its tools with a description the model readsAgent publishes an "Agent Card" saying what it can do
Main riskPoisoned tool descriptions, over-broad permissionsFake or compromised agents, oversharing data
For managers: treat a new MCP server or partner agent like a new vendor. Someone reviews it, someone owns it, and it gets the smallest access that does the job.
For engineers: tool descriptions and agent replies are text the model reads, so they can carry instructions. This is the indirect prompt injection from Ep 1, arriving through a new door.

Background to check before quoting: MCP was published as an open standard by Anthropic in late 2024; A2A was announced by Google in 2025 and later moved to an open foundation. Confirm dates and current governance on the official sites before presenting.

Real cases (reported; open the original source before quoting details)

Researchers have already shown this

2025 · Reported research: "tool poisoning"Security researchers published demonstrations where hidden instructions inside an MCP tool's description made an AI assistant leak data from other connected tools. This was a research demo, not a reported breach.Lesson: review and pin every tool. Verify the original write-up before quoting.
Feb 2023 · Bing Chat "Sydney" (from Ep 1)A prompt injection made Bing Chat reveal its hidden instructions.Lesson: anything the model reads can carry instructions, tool descriptions included.
